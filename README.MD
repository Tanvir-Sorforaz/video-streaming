# Share the Video

Run the server first:

```bash
npm start
```

## Using a Public IP

If you have a real/public IP address, run the server and share this link:

```text
http://YOUR_IP:6996
```

To find your public IP, search **"what is my IP"** on Google. The port is shown in the terminal.

## Use Tailscale

If you have a shared/private network, use Tailscale VPN:

1. Sign in to Tailscale with the same account as your friends.
2. Connect Tailscale on every device that will watch the video.
3. Find your Tailscale IP address from the Tailscale icon in the system tray.
4. Share this link:

```text
http://YOUR_TAILSCALE_IP:6996
```
